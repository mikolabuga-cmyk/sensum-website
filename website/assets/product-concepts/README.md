# Product interface concepts

Original SVG illustrations created for the Sensum scrolling product scene, October 18, 2026.

These are illustrative interface concepts, not client work or measured product results. The chart is schematic and contains no numerical claims. They replace the three reference photographs while retaining the existing image frames and scroll animation. Vector artwork keeps the interface details sharp at every display density without additional runtime code or image downloads.
